# components/ui

Componentهای عمومی و کاملاً مستقل از Domain: Button, Input, Modal, Badge, Toast,
Dropdown و... . این Componentها هیچ منطق مربوط به محصول/سبد خرید/سفارش ندارند و
باید در هر پروژه دیگری هم قابل استفاده مجدد باشند. Componentهای Domain-specific
(مثل ProductCard) در `components/product/` و... قرار می‌گیرند، نه اینجا (بخش ۶
پرامپت مادر).
